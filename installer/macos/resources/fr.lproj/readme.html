À lire avant l'installation

  • AbosCluster est installé dans Applications ▸ AbosCluster, qui contient deux icônes : AbosCluster et Désinstaller AbosCluster.
  • Tous les fichiers du programme sont masqués à l'intérieur de l'application.
  • Une version précédente est remplacée automatiquement.
  • Vos projets et vos données ne sont jamais modifiés ni supprimés.
