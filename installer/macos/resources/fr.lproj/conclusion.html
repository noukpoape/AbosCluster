AbosCluster est installé

  • Lancez-le depuis Applications ▸ AbosCluster ou le Launchpad.
  • Le bouton Help affiche le manuel d'utilisation dans la langue choisie (bouton langue).
  • Pour le désinstaller : Applications ▸ AbosCluster ▸ Désinstaller AbosCluster.
  • Vous pouvez supprimer le fichier .pkg téléchargé.
